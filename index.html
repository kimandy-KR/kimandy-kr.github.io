Youtube 작업장

소개개인정보처리방침이용약관

소개

「Youtube 작업장」은 운영자 본인이 소유한 YouTube 채널의 영상을 비공개(private) 상태로 업로드하고, 제목·설명·썸네일·자막 같은 메타데이터를 정리하기 위해 운영자의 PC 에서만 실행하는 명령줄 도구입니다. 일반 사용자에게 배포하거나 판매하지 않으며, 웹 서비스나 서버가 없습니다.

Google 의 YouTube Data API v3(권한 범위 youtube.force-ssl)를 사용해 운영자 채널에 대해 다음 작업만 합니다: 영상 업로드(비공개) · 썸네일 설정 · 자막 업로드 · 업로드 결과와 채널 정보 조회. 영상을 공개하거나 예약 공개하는 기능은 코드에 없습니다.

개인정보처리방침

  • 수집하는 개인정보: 없음. 이 도구는 운영자 본인 외 누구의 데이터도 수집·저장·전송하지 않습니다.
  • Google 계정 데이터: 운영자가 Google 동의 화면에서 허용한 OAuth 토큰은 운영자 PC 의 로컬 폴더에만 저장되며, 운영자 채널에 대한 위 작업에만 쓰입니다. 제3자에게 제공·판매·공유하지 않고, 광고·신용 평가·AI 모델 학습 등 다른 목적으로 쓰지 않습니다.
  • 서버·쿠키·분석 도구: 없음. 데이터는 운영자 PC 와 Google API 사이에서만 오갑니다.
  • Google API 서비스 사용자 데이터 정책 준수: 이 도구의 Google API 로 받은 정보 사용과 다른 앱으로의 전송은 Google API Services User Data Policy(제한적 사용 요건 포함)를 따릅니다.
  • 삭제·철회: 운영자는 언제든 로컬 토큰 파일을 지우고, Google 계정 → 보안 → 서드파티 앱 액세스에서 이 앱의 접근 권한을 해제할 수 있습니다.
  • 문의: 동의 화면에 표시된 지원 이메일로 연락할 수 있습니다.

이용약관

  • 이 도구는 운영자 본인 전용이며, 타인의 사용을 허가하지 않습니다.
  • 도구는 「있는 그대로」 제공되며, 사용으로 생기는 결과(업로드 실패·할당량 초과 등)의 책임은 운영자 본인에게 있습니다.
  • YouTube 이용은 YouTube 서비스 약관과 Google 개인정보처리방침을 따릅니다.

이 페이지는 Google OAuth 동의 화면의 앱 홈페이지·개인정보처리방침·이용약관 링크로 쓰이기 위해 만들어졌습니다.
